📱 1 分钟配置 iOS 一键打卡庆祝
完全无需安装证书或重签！直接用苹果自带「提醒事项 + 日历 + 快捷指令」即可实现桌面一键打卡并弹出本庆祝页：
第 1 步
打开 iPhone 自带的 「快捷指令」 App，点击右上角 「+」 新建快捷指令，命名为 「微行动完成」。
第 2 步
添加以下 4 个官方动作（搜索动作名称即可添加）：
1. 查找提醒事项：筛选条件设为「未完成」（可选列表：微行动）；
2. 从列表中选择：勾选你想完成的那个提醒事项；
3. 编辑提醒事项：将「选择的项目」设为「已完成」；
4. 添加新日程（可选）：标题填 [微行动] ✅ [选择的项目]，开始时间选「当前日期」。
第 3 步
最后添加一个 「打开 URL」 动作，填入下方庆祝网页地址（把末尾的 任务名称 替换为快捷指令变量 「选择的项目」）：
第 4 步
将该快捷指令 「添加到主屏幕」 或放到桌面小组件。以后每次点一下，勾选任务后就会自动记入苹果日历并弹出此全屏礼花庆祝页！
